# 🚀 Interactive Cyber Security Access Control System (C-Language)

## 📝 Project Description
This repository contains an interactive Access Control and Authentication script written in **C**. Unlike static scripts, this version utilizes standard input streams (`scanf`) to dynamically accept a `User ID` and `Password` from the user at runtime.

The program evaluates the inputs against secure mock-credentials using nested `if-else` conditional branching, simulating a real-world server login gateway.

## 🛠️ Requirements
* **Operating System:** Linux (Ubuntu/Debian via VMware)
* **Compiler:** GCC (GNU Compiler Collection)
